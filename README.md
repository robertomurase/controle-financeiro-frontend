# Controle Financeiro 2.0 - Frontend Angular (v4 com Leitor QR Code NFC-e)

Este é o projeto frontend em Angular para o sistema Controle Financeiro 2.0, incluindo **Leitor de QR Code para NFC-e via Câmera/Webcam e Arquivo de Foto**.

## Novidades na v4:
- 📱 **Leitor de QR Code da NFC-e com suporte a Câmera/Webcam**: Escaneamento em tempo real direto do celular ou computador.
- 📸 **Upload de Foto de QR Code**: Permite carregar uma imagem da nota fiscal.
- 🔗 **Entrada Manual**: Mantém opção de colar o link diretamente.
- 🇧🇷 **Formatação Brasileira (pt-BR)**: Valores em Reais no formato `R$ 10.000,00`.
- 💎 **Layout Executivo Dark Navbar**: Visual baseado no Finanças Pro.

## Como rodar o projeto

1. Certifique-se de que o backend Node.js está rodando na porta 3000 (`http://localhost:3000`).
2. Abra este diretório no terminal e instale as dependências:
   ```bash
   npm install
   ```
3. Inicie a aplicação Angular:
   ```bash
   npm run start
   ```
4. Acesse no seu navegador:
   `http://localhost:4200`
